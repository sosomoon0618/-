# 出片没｜交互确认单 v1

**端形态**：移动端 H5 / PWA，390px 黑白灰线框。  
**目的**：先验证页面层级、信息结构和点击结果；确认后才生成可点击 HTML 低保真原型。  
**不模拟**：真实图片导入、相机权限、保存至系统相册、AI、云同步。

## 1. 已确认的交互原则

- 个人姿势库是长期总库；主题单是一次出行/拍摄的独立轻量收藏夹。
- 主题单仅包含名称、人物与穿搭、自由备注和引用图片。
- 不单独设置“拍摄主题”字段；游乐园、毕业、香水和个人随手备注词统一使用自由「拍摄关键词」，可搜索和筛选。
- 用户先可「查看参考」，再自行决定是否「用手机照着拍」。
- 查看参考不申请相机权限，可供另一台手机、相机或朋友帮拍时使用。
- 构图辅助线为可开关的三分法九宫格，默认关闭；不修改参考图，也不进入拍摄成片。
- 手机相机首版不做 AI 姿势评分、动作纠正或自动快门。

## 2. 原型范围与入口

| 编号 | 页面 / 弹层 | 进入方式 | 主操作 |
|---|---|---|---|
| P1 | [姿势库] | 默认首页 | 导入、搜索、筛选、打开灵感卡 |
| P2 | [灵感卡详情] | P1 / P5 的任一灵感卡 | 查看参考、加入主题单、编辑标签 |
| P3 | [查看参考] | P2；P7 选图后 | 构图辅助线、缩放、用手机照着拍 |
| P4 | [主题单列表] | 底部导航 | 新建主题单、打开主题单 |
| P5 | [主题单详情] | P4 的任一主题单 | 编辑、添加灵感、打开卡片 |
| P6 | [新建/编辑主题单] | P4/P5 | 保存主题名称、人物穿搭、备注 |
| P7 | [照着拍：选参考图] | 底部导航 | 选图并进入 P3 |
| P8 | [用手机照着拍] | P3 | 调引导工具、拍摄 |
| M1 | 「筛选面板」 | P1 | 应用/清除筛选 |
| M2 | 「主题单选择器」 | P2 / 导入流程 | 选择多个主题单 |
| M3 | 「确认弹窗」 | 删除 / 移出主题等风险操作 | 确认或取消 |

**不覆盖**：我的页面的完整视觉、官方精选运营后台、AI、账户/付费、云同步、真实系统权限和存储异常。

## 3. 页面流

```text
P1 姿势库 ──点击任一卡──→ P2 灵感卡详情 ──查看参考──→ P3 查看参考
      │                          │                            ├─ 仅看图 / 开关构图线
      ├─导入──→ 快速整理 ────────┘                            └─ 用手机照着拍 → P8
      └─筛选──→ M1 筛选面板

P4 主题单列表 ──新建──→ P6 新建主题单 ──保存──→ P5 主题单详情
      │                                           │
      └─点击任一主题单────────────────────────────┘
P5 ──添加姿势库灵感──→ 选择灵感卡 ──确认──→ P5
P2 / 快速整理 ──加入主题单──→ M2 主题单选择器 ──确认──→ 返回来源页

P7 照着拍 ──选择参考图──→ P3 查看参考 ──用手机照着拍──→ P8
```

返回规则：P2 返回 P1 时保留搜索、筛选和滚动位置；P5 返回 P4 时保留列表位置；P3/P8 返回各自进入来源；选择器或弹窗取消时丢弃未确认草稿。

### M1「筛选面板」字段与选择规则（v1.1 修订）

筛选项按字段分组展示，不将不同含义的标签混在同一组。每个字段第一项固定为「不限」；点击后只清空该字段，不影响其他已选字段。

| 字段 | 可选值来源 | 选择方式 | 「不限」效果 |
|---|---|---|---|
| 地点 / 点位 | 已存在的地点、点位标签 | 可多选 | 不限制地点 / 点位 |
| 人数 | 已存在的人数标签 | 可多选 | 不限制人数 |
| 景别 | 已存在的景别标签 | 可多选 | 不限制景别 |
| 动作 | 已存在的动作标签 | 可多选 | 不限制动作 |
| 拍摄关键词 | 已存在的拍摄关键词 | 可多选 | 不限制关键词 |
| 整理状态 | 待整理、已整理 | 单选 | 不限制整理状态 |

同一字段内多个值为“任一命中”，不同字段之间为“同时命中”。点击「清除」恢复所有字段为不限；点击「关闭」不应用本次弹层内的草稿；点击「应用」写入当前列表并保留至用户主动清除。

## 5. 关键点击映射

| 页面 | 可点击元素 | 结果 |
|---|---|---|
| P1 | 导入 | 打开导入与快速整理流程；图片唯一必填，标签可跳过。 |
| P1 | 搜索 / 筛选 | 刷新当前卡片列表；无结果展示筛选空态。 |
| P1/P5 | 任一灵感卡 | 打开对应的 P2，不固定第一张卡。 |
| P2 | 查看参考 | 进入 P3，不申请相机权限。 |
| P2 | 加入主题单 | 打开 M2；可多选；取消回滚本次草稿。 |
| P3 | 构图辅助线 | 即时显示/隐藏九宫格；不修改图片。 |
| P3 | 用手机照着拍 | 进入 P8；真实产品在此时才申请相机权限。 |
| P4 | 新建主题单 | 进入 P6。 |
| P5 | 添加 | 选择“从姿势库挑选”或“直接导入图片”。 |
| P8 | 工具栏 | 即时切换透明度、镜像、构图线或倒计时的原型状态。 |
| P8 | 拍摄 | 显示不含参考图和辅助线的结果预览。 |

- 是否按本页的 P1–P8 页面范围生成 HTML 原型；
