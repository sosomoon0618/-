## 查看方式

用浏览器打开 HTML 文件即可。原型为 390px 宽的移动端 H5 线框，桌面打开时会显示手机外框。

## 已模拟

- 姿势库、搜索、按字段分组的筛选面板（每组「不限」）、待整理状态与无标签导入；
- 灵感卡详情、结构化标签与拍摄关键词编辑、加入主题单、删除影响确认；
- 主题单创建、编辑、添加姿势库灵感、删除；
- 主题单内直接导入后自动入库并加入当前主题单；
- 查看参考、构图辅助线开关与轻量手势提示；
- 相机用途说明、拒绝权限后的查看参考恢复路径；
- 模拟相机、透明度/镜像/构图线/计时的可见状态、拍摄结果预览；
- 页面来源返回：主题单 → 卡片 → 参考 → 相机 → 结果可逐级返回；
- 顶部原型控制条可切换空态、无结果和相机权限拒绝。

## 原型不模拟

真实图片文件读取、系统相机权限、实时摄像头、系统相册保存、AI、云同步和账户。权限弹层仅模拟用户理解与恢复路径。
