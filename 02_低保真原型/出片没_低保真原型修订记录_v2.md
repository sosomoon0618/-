## v2.1：筛选与点击稳定性修订

| 问题 | 修订结果 |
|---|---|
| 筛选项混在同一组 | 筛选面板改为「地点 / 点位、人数、景别、动作、拍摄关键词、整理状态」六个独立字段组。 |
| 无法表达“不筛某字段” | 每个字段首项增加「不限」；只清空该字段，不影响其他条件。 |
| 组合筛选规则不清晰 | 同字段多选为任一命中；不同字段为同时命中；整理状态单选。 |
| 点击后出现嵌入预览错误 | 去除了嵌入式预览可能不兼容的 `structuredClone` 与 `Array.prototype.at()`；筛选改为草稿态，只有「应用」才更新列表，关闭不改变已应用条件。 |

已完成脚本语法检查，以及地点、待整理、跨字段组合、同字段多选四类筛选逻辑校验。实际嵌入式预览环境仍需用户再次点击确认。

## 本轮保留的边界

- 仍是黑白灰低保真原型；图片导入、相机、系统权限、手势、保存设备均为模拟。
- 所有数据仅在当前演示会话内；点击“重置演示”会恢复样例数据。
- 实际视觉、热区、键盘遮挡、无障碍和移动设备手势尚未获得可访问浏览器预览，不能宣称已完成视觉验收。

## 下一步

请按下列两条路径点击复审：

1. **主题准备**：主题单 → 添加 → 直接导入图片 → 直接保存 → 打开新图 → 整理灵感 → 保存 → 返回主题单。
2. **现场参考**：主题单 → 灵感详情 → 查看参考 → 用手机照着拍 → 允许并继续 → 调整工具 → 拍摄 → 重拍 / 返回。

交互确认后，才进入 `04_UI设计规格`，并回写两份 PRD 的页面级状态与验收标准。
