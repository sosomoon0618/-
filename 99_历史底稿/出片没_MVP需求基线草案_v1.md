# MVP-001_出片没：个人姿势库、主题单与照着拍

> 关联：本需求为 0→1 MVP，当前项目未建立独立的全局异常、非功能性与埋点规范。本文仅定义本模块特有规则；浏览器级网络、权限与存储失败按第 7 章处理。

| 版本 | 日期 | 变更内容 | 变更需求编号 |
|---|---|---|
| v1.0 | 2026-11-04 | 首版 MVP 需求方案 | MVP-001 |

## 1. 背景与目标

### 1.1 背景

用户会长期保存小红书截图、相册图片等拍照灵感。现有多维表格能通过地点、点位、动作、道具、人数、景别与光线等字段帮助检索，但手机端录入和现场查找成本高：用户既不愿每次存图都填写表单，也无法在目的地快速把一组参考图转化为可执行的拍摄指引。

首版验证的不是“AI 能否识别姿势”，而是用户是否愿意将灵感沉淀为个人姿势库，并在一次具体出行前建立主题单、在现场打开参考图照着拍。

### 1.2 本模块目标

- 建立**个人姿势库**：用户可随手导入灵感图，按需补充标签，并通过筛选与搜索找回。
- 建立**主题单**：用户可为一次出行或拍摄创建轻量收藏夹，附上人物穿搭和自由备注。
- 建立**照着拍**：用户可从姿势库或主题单进入相机，以半透明参考图辅助构图和摆姿势。
- 保证免费核心闭环可用：首版不依赖云端 AI、不要求注册、不公开用户图片。

### 1.3 成功标准

| 指标 | 现状 | 目标 | 观测方式 |
|---|---|---|---|
| `M_import_to_library` | 无产品基线 | 验证用户能完成图片入库 | 统计导入成功与导入放弃 |
| `M_theme_creation` | 无产品基线 | 验证用户愿为具体出行创建主题单 | 统计主题单创建与图片加入主题单 |
| `M_reference_to_camera` | 无产品基线 | 验证主题单能在现场促进照着拍 | 统计从卡片进入相机、完成拍摄 |
| `M_repeat_retrieval` | 无产品基线 | 验证私库有长期找回价值 | 统计非首次导入日的搜索、筛选、再次打开卡片 |

## 2. 名词与数据约定

| 名称 | 说明 |
|---|---|
| 个人姿势库 | 当前设备上所有用户灵感卡的唯一总池；图片只在此处存一份。 |
| 灵感卡 | 姿势库中的一张参考图及其通用标签、标题、备注与来源标识。灵感卡不包含主题名称。 |
| 待整理 | 已完成本地导入、但用户未主动保存任一通用标签的灵感卡状态；不妨碍浏览、搜索标题或加入主题单。 |
| 已整理 | 用户已保存至少一个通用标签的灵感卡状态。 |
| 主题单 | 为一次出行、拍摄或灵感项目创建的轻量收藏夹。主题单保存对灵感卡的引用，不复制图片。 |
| 主题成员 | 主题单内的一位人物及其穿搭说明；仅服务当前主题单，不写回灵感卡。 |
| 通用标签 | 用于个人姿势库检索的地点、点位、动作/行为、道具、人数、景别、光线与自定义标签。 |
| 参考图叠加 | 在实时相机预览上显示的半透明灵感卡图片；仅作取景辅助，不能出现在拍摄成片中。 |
| 本地保存 | 数据保存在当前浏览器/PWA 的本地存储空间。清除浏览器站点数据、卸载应用或更换设备可能导致数据不可恢复。 |
| 官方精选 | 平台提供的、已确认可使用的示例灵感内容；与用户私库逻辑隔离。 |

### 2.1 数据关系

```text
个人姿势库 1 ── N 灵感卡
主题单 N ── N 灵感卡（通过主题引用关系关联）
主题单 1 ── N 主题成员
```

一张灵感卡可被加入多个主题单；移出任一主题单不删除灵感卡。主题单不是灵感卡字段，主题名称不进入姿势库的通用标签体系。

## 3. 范围

### 3.1 本次包含

- 移动端 Web / PWA 的本地姿势库。
- 从设备相册导入单张图片、拍照后存入姿势库。
- 灵感卡的轻量标签、标题、自由备注、搜索与分层筛选。
- 主题单的新建、编辑、删除、人物穿搭、自由备注与引用图片管理。
- 从姿势库或主题单进入「照着拍」相机。
- 相机中的参考图透明度、缩放、拖动、镜像、网格、倒计时与拍摄结果本地保存。
- 小规模官方精选内容展示；官方内容必须经过素材来源审核后才可配置上线。

### 3.2 本次不做

| 不做项 | 说明 | 后续计划 |
|---|---|---|
| 云端账户、跨设备同步与云存储 | 首版不要求登录，数据默认本地保存。 | 作为独立会员能力评估。 |
| 云端 AI 自动打标、自然语言搜索、AI 建主题单 | 首版以手动轻量整理保证免费可用。 | 第二阶段，按免费试用与 AI 点数设计。 |
| 人物轮廓/骨架提取、实时姿势评分、自动快门 | 首版只显示原参考图叠加。 | 第二阶段。 |
| 社区、用户公开投稿、点赞评分与评论 | 避免内容审核与低质内容问题。 | 验证个人库价值后再评估。 |
| AI 修图、消路人、滤镜、文案生成 | 不属于首版核心闭环。 | 后续出片工具链规划。 |
| 行程、天气、地图、拍摄优先级或拍摄状态管理 | 主题单只作为轻量收藏夹。 | 基于用户反馈评估。 |
| 自动抓取、爬取或公开再分发第三方平台图片 | 不做。用户仅能将已在设备中的图片导入私库。 | 无。 |

### 3.3 影响面

- 页面：姿势库、灵感卡详情、导入与整理、主题单列表、主题单详情、照着拍相机、我的。
- 数据：当前设备的灵感卡、标签、主题单、主题成员、主题引用关系和拍摄结果。
- 权限：设备相册选择、设备相机；均按用户操作按需申请。
- 外部依赖：首版无云端 AI、无第三方内容抓取、无账户服务依赖。

## 4. 用户与角色

### 4.1 目标用户

| 用户类型 | 特征 | 本次覆盖 |
|---|---|---|
| 灵感收集型用户 | 会保存拍照参考，但不愿维护复杂表格。 | 是 |
| 出行/拍摄准备型用户 | 会在出行、约会、聚会、毕业照等场景前准备拍照灵感。 | 是 |
| 专业摄影工作者 | 需要团队协作、客户管理或专业器材工作流。 | 否 |

### 4.2 登录态

首版没有账户体系，因此不存在登录入口、登录拦截或登录回跳。所有用户均以当前设备的本地身份使用产品；更换设备或清除站点数据不会自动恢复数据。

## 5. 功能详述

### 5.0 模块定位与主路径

底部主导航固定为「姿势库」「主题单」「照着拍」「我的」。首次进入默认落在 `[姿势库]`；若本地没有任何灵感卡，展示首次空态并引导导入。

主路径：

```text
▶ 平时存图：姿势库 → 导入图片 → 待整理/已整理 → 详情
▶ 出行准备：主题单 → 新建主题单 → 从姿势库选择/直接导入 → 主题单详情
▶ 到现场拍摄：主题单或详情 → 照着拍 → 相机叠加 → 拍摄结果本地保存
```

离开页面后，姿势库保留本次搜索词、已确认筛选和滚动位置；主题单详情保留滚动位置。未确认保存的表单草稿按各自页面规则处理。

### 5.1 [姿势库]

**定位**：承载所有灵感卡的长期私库，用户可导入、浏览、查找、整理并将卡片加入主题单。

#### 展示字段

| 区域 | 字段 / 文案 | 业务含义 | 展示 / 取值来源 | 格式与空值展示 |
|---|---|---|---|---|
| 顶部 | 「搜索框」 | 在私库中找回灵感 | 用户输入的关键词；匹配标题、备注、通用标签和自定义标签 | 空时显示占位文案 `“搜索地点、动作或灵感”` |
| 顶部 | 「筛选按钮」 | 打开筛选面板 | 本地可用筛选项 | 无可用标签时仍可点击，筛选面板显示空选项 |
| 顶部 | 「导入按钮」 | 新增灵感卡入口 | 固定组件 | 始终展示 |
| 快捷区 | 「待整理」 | 提醒尚未补标签的图片 | `待整理` 灵感卡数量 | 数量为 0 时隐藏入口 |
| 卡片 | 参考图 | 用户要复刻的画面 | 灵感卡原图或官方精选图 | 图片不可读取时显示占位并保留卡片操作 |
| 卡片 | 标题 | 帮助用户记忆图片用途 | 用户填写的标题 | 空值显示 `“未命名灵感”` |
| 卡片 | 关键标签 | 辅助快速浏览 | 优先展示地点、动作、人数、景别中已填的最多两类 | 无标签显示 `“待整理”` |
| 卡片 | 来源标记 | 区分内容归属 | `我的导入` 或 `官方精选` | 固定显示 |

#### 状态判定与展示

| 状态 | 判定条件 | 视觉表现 | 核心交互 |
|---|---|---|---|
| 首次空态 | 本地没有任何灵感卡 | 展示导入说明与「导入第一张图」 | 导入图片 |
| 无搜索结果 | 已输入关键词或筛选条件，但无卡片命中 | 展示 `“没有找到匹配的灵感”` 与「清除筛选」 | 清除关键词与筛选 |
| 待整理列表 | 用户点击「待整理」 | 仅显示 `待整理` 卡片 | 编辑标签、加入主题单 |
| 常规列表 | 其它情况 | 按创建时间倒序展示全部命中卡片 | 打开详情、筛选、导入 |
| 本地读取失败 | 已有本地记录但图片无法读取 | 图片位显示占位，卡片保留标题与删除入口 | 删除无效卡片或返回 |

#### 筛选与浏览交互

默认只展示主筛选：地点/点位、人数、景别、动作。用户点击「更多筛选」后才展示道具、光线、自定义标签、内容来源与整理状态。

同一筛选维度内为“任一选中值命中”，不同筛选维度之间为“同时命中”。例如选中“单人”和“全身”后，仅保留同时含两类标签的卡片；同一维度选中“坐”和“站”后，卡片含任一动作即可。

| 交互对象 | 可用条件 | 用户动作 | 即时反馈 | 结果 / 去向 | 异常 / 禁用 |
|---|---|---|---|---|---|
| 「导入按钮」 | 浏览器可打开图片选择器 | ▶ 点击 → 选择一张图片 | 显示本地读取进度 | 读取成功后进入「快速整理面板」 | 文件不可读或格式不支持时见 7.1 |
| 「搜索框」 | 姿势库有卡片 | 输入、清空关键词 | 列表随输入更新 | 保留匹配卡片；清空后恢复当前筛选结果 | 无结果时展示无搜索结果状态 |
| 「筛选按钮」 | 姿势库有卡片 | 点击打开「筛选面板」 | 显示当前已选数量 | 用户可选择、清除或应用筛选 | 无可选标签不阻断打开 |
| 「筛选面板-应用」 | 面板已打开 | 点击「应用」 | 面板关闭 | 列表按草稿筛选刷新，筛选状态被记忆 | 无命中展示无搜索结果状态 |
| 「筛选面板-取消/关闭」 | 面板已打开 | 点击取消、关闭或遮罩 | 关闭面板 | 放弃本次未应用的筛选草稿；保留进入前已应用筛选 | 无 |
| 「筛选面板-清除」 | 已存在草稿或已应用筛选 | 点击「清除全部」 | 已选状态清空 | 面板内显示全部可选项；点击应用后恢复未筛选列表 | 无 |
| 任一灵感卡 | 卡片可读取或有可显示元信息 | 点击卡片 | 页面转场 | 进入[灵感卡详情] | 无效图片仍可进入详情并执行删除 |
| 「待整理」 | 待整理数量大于 0 | 点击 | 列表切换 | 展示待整理列表 | 无 |

### 5.2 [导入与快速整理面板]

**定位**：在不强制填表的前提下，将新图片存入姿势库；用户可当下补最少信息，或直接跳过。

#### 展示字段

| 区域 | 字段 / 文案 | 业务含义 | 展示 / 取值来源 | 格式与空值展示 |
|---|---|---|---|---|
| 预览区 | 图片预览 | 确认当前将导入的素材 | 本次选择的本地文件 | 读取中显示加载态；读取失败不展示表单 |
| 表单 | `标题` | 用户对图片的个人记忆 | 可选手填 | 空值时不生成默认标题 |
| 表单 | `加入主题单` | 同时把新图放入一次性收藏夹 | 用户多选主题单 | 默认不选；主题单为空时显示创建入口 |
| 表单 | `快捷标签` | 快速提高后续检索能力 | 用户从地点、人数、景别、动作四类中按需选择 | 全部可空 |
| 操作区 | 「直接保存」 | 不整理也能入库 | 固定操作 | 始终可点击 |
| 操作区 | 「保存并继续整理」 | 保存后进入详情完善更多字段 | 固定操作 | 始终可点击 |

#### 交互与结果

| 交互对象 | 可用条件 | 用户动作 | 即时反馈 | 结果 / 去向 | 异常 / 禁用 |
|---|---|---|---|---|---|
| 「加入主题单」 | 已存在至少一个主题单 | 点击打开「主题单选择器」 | 显示已选主题单数量 | 确认后回显主题单名称，可移除 | 选择器规则见 5.5 |
| 「直接保存」 | 图片读取成功 | 点击 | 按钮进入处理中，防止重复点击 | 新建灵感卡；有快捷标签则为`已整理`，否则为`待整理`；返回姿势库并展示 `“已存入姿势库”` | 本地保存失败时保留表单与图片预览，见 7.1 |
| 「保存并继续整理」 | 图片读取成功 | 点击 | 与直接保存相同 | 新建灵感卡后进入[灵感卡详情]编辑态 | 本地保存失败时原地提示 |
| 「取消/关闭」 | 尚未保存 | 点击 | 关闭面板 | 放弃本次导入草稿，不新增灵感卡 | 不弹二次确认 |

### 5.3 [灵感卡详情]

**定位**：展示一张灵感卡，并提供完整标签编辑、加入主题单、照着拍和删除能力。

#### 展示字段

| 区域 | 字段 / 文案 | 业务含义 | 展示 / 取值来源 | 格式与空值展示 |
|---|---|---|---|---|
| 主图区 | 参考图 | 当前复刻依据 | 灵感卡图片 | 无法读取时显示错误占位与删除入口 |
| 信息区 | 标题 | 个人记忆名称 | 灵感卡`标题` | 空值显示 `“未命名灵感”` |
| 信息区 | 通用标签 | 用于姿势库检索 | 灵感卡已保存标签 | 未填写的字段不展示标签 |
| 信息区 | 自由备注 | 记录不适合结构化的想法 | 灵感卡`备注` | 空值显示 `“暂无备注”` |
| 信息区 | 已加入主题单 | 说明卡片当前被哪些主题引用 | 本地主题引用关系 | 未加入时显示 `“未加入主题单”` |
| 操作区 | 「照着拍」 | 以当前图作为相机引导 | 当前灵感卡 | 图片可读取时可用；否则禁用 |

#### 字段编辑规则

| 字段 | 来源 | 取值规则 | 校验 |
|---|---|---|---|
| `标题` | 用户输入 | 自由文本，用于关键词搜索 | 可空；仅空白字符按空值保存 |
| `地点` | 用户选择或新建个人标签 | 可选择多个地点词 | 可空；同一字段内不允许重复值 |
| `点位` | 用户选择或新建个人标签 | 可选择多个具体位置/构图位置词 | 可空；同一字段内不允许重复值 |
| `动作/行为` | 用户选择或新建个人标签 | 例如站、坐、走、回头、喝咖啡 | 可空；同一字段内不允许重复值 |
| `道具` | 用户选择或新建个人标签 | 例如咖啡、花、帽子 | 可空；同一字段内不允许重复值 |
| `人数` | 用户单选 | 单人、双人、多人 | 可空；新值覆盖旧值 |
| `景别` | 用户单选 | 特写、半身、全身、远景 | 可空；新值覆盖旧值 |
| `光线` | 用户选择或新建个人标签 | 例如日落、逆光、室内暖光 | 可空；同一字段内不允许重复值 |
| `自定义标签` | 用户输入 | 补充个人可搜索词 | 可空；去除首尾空格后去重 |
| `备注` | 用户输入 | 自由长文本，不进入筛选面板但参与关键词搜索 | 可空 |

保存任一通用标签后，灵感卡从`待整理`变为`已整理`；删除全部通用标签后，恢复为`待整理`。标题、备注和主题引用不影响整理状态。

#### 「标签选择器」规则

每个多选标签字段（地点、点位、动作/行为、道具、光线、自定义标签）复用「标签选择器」：打开时展示当前字段已保存标签和该字段在个人姿势库中已出现的标签；用户可点击切换选中，也可输入新词并点击「添加」创建个人标签。新词仅在点击选择器「确定」且详情页「保存」后写入灵感卡；选择器取消、关闭或遮罩关闭时，丢弃本次标签草稿并恢复为打开前的已保存值。`人数`和`景别`为单选，用户点击新值后替换旧值；点击已选值可清空。

#### 交互矩阵

| 交互对象 | 可用条件 | 用户动作 | 即时反馈 | 结果 / 去向 | 异常 / 禁用 |
|---|---|---|---|---|---|

## 6. 业务规则

### 6.1 核心规则

| 编号 | 规则 | 说明 |
|---|---|---|
| R1 | 图片唯一存储 | 同一灵感卡在个人姿势库中只保留一份图片；主题单只保存卡片引用。 |
| R2 | 导入默认可跳过整理 | 用户导入图片时不填写标题、标签或主题单也可保存；未保存通用标签时标记为`待整理`。 |
| R3 | 标签只服务姿势库 | 通用标签用于个人姿势库检索；主题名称、主题人物、主题备注不反向写入灵感卡标签。 |
| R4 | 主题单为轻量收藏夹 | 主题单仅管理名称、主题成员与穿搭、自由备注和引用图片；不新增行程、任务、状态或优先级字段。 |
| R5 | 主题引用独立于原图 | 移出主题单或删除主题单只删除引用；删除灵感卡才会删除图片及其所有主题引用。 |
| R6 | 私库默认不公开 | 用户导入的图片和标签只在当前设备可见，不进入官方精选、不公开、不用于训练或内容分发。 |
| R7 | 官方精选来源受控 | 官方精选仅可使用自制、明确授权或确认可商用的素材；不得以用户私库图片补充官方内容。 |
| R8 | 相机不产生 AI 判断 | 相机仅做参考图叠加、构图辅助和拍摄；不上传相机流，不输出姿势评分或衣着判断。 |
| R9 | 成片不含引导层 | 拍摄结果只包含实时相机画面，参考图、网格和其它引导层不得进入成片。 |
| R10 | 删除需明确确认 | 删除灵感卡、删除主题单、从主题单移除图片均为风险操作，必须二次确认。 |

### 6.2 数据状态流转

| 当前状态 | 事件 | 目标状态 | 条件 |
|---|---|---|---|
| 无灵感卡 | 导入图片并保存 | 待整理 | 未保存任一通用标签 |
| 无灵感卡 | 导入图片并保存 | 已整理 | 至少保存一个通用标签 |
| 待整理 | 保存任一通用标签 | 已整理 | 本地更新成功 |
| 已整理 | 删除全部通用标签 | 待整理 | 本地更新成功 |
| 灵感卡存在 | 加入主题单 | 灵感卡存在 | 创建新的主题引用，不改变整理状态 |
| 灵感卡存在 | 删除灵感卡并确认 | 已删除 | 同时删除图片、标签与所有主题引用 |
| 主题单存在 | 删除主题单并确认 | 已删除 | 删除主题单、成员与引用，不删除任何灵感卡 |

### 6.3 本地存储与恢复

- 产品必须在用户主动保存动作成功后才写入本地数据；取消、关闭和读取失败不产生半成品记录。
- 本地存储空间不可用时，不静默删除旧数据腾空间；必须保留现有数据并提示用户清理空间或删除不需要的灵感卡。
- 首版不提供云端备份、恢复、跨设备迁移或“清空全部数据”入口。
- 浏览器清除站点数据、卸载 PWA、使用无痕模式或更换设备可能导致本地数据消失；该限制在首次进入和[我的]中可见。

### 6.4 第二阶段 AI 边界

第二阶段 AI 可以读取用户主动选择的图片，以自动补充本需求中已有的通用标签字段，或理解自然语言查询；不得新建与首版字段模型冲突的平行标签体系。AI 调用前必须明确告知图片会离开本地设备，并展示可用试用额度或点数消耗；本需求不定义 AI 定价、额度或扣费规则。

## 7. 校验与异常

### 7.0 处理原则

- **前置校验**：浏览器可立即识别的图片读取、必填名称、权限状态在触发操作时拦截，不创建半成品数据。
- **单次操作**：一次保存只展示首个命中的可修复异常；用户修复后可原地重试，已有输入与选择必须保留。
- **本地优先**：首版不依赖网络。网络不可用不影响已缓存的个人姿势库、主题单和相机引导；官方内容无法首次加载时不影响用户私库。
- **不可逆操作**：删除前必须通过明确文案说明影响；取消、关闭或遮罩关闭均不改变数据。

### 7.1 选择与导入图片

| 异常场景 | 判定逻辑 | 交互 | 提示文案 | 文案示例 |
|---|---|---|---|---|
| 未选择图片 | 用户关闭系统选择器且未返回文件 | 返回导入入口，不创建记录 | 不展示错误提示 | 无 |
| 格式不支持 | 浏览器无法解码或文件不是可读取的图片 | 留在导入入口，允许重新选择 | Toast | `“这张图片暂时无法导入，请换一张试试”` |
| 图片读取失败 | 本地文件读取过程失败 | 不打开快速整理面板，允许重新选择 | Toast | `“图片读取失败，请重新选择”` |
| 本地空间不足 | 保存灵感卡时浏览器返回存储失败 | 保留当前表单，不删除已有数据，提供重试 | 阻断弹窗 | `“本地空间不足，暂时无法保存。请删除不需要的灵感后重试。”` |
| 重复导入 | 用户导入与既有卡片内容相同的图片 | 首版不做自动去重，按独立灵感卡保存 | 无 | 无 |

### 7.2 主题单与标签编辑

| 异常场景 | 判定逻辑 | 交互 | 提示文案 | 文案示例 |
|---|---|---|---|---|
| 主题名称为空 | 点击保存时，名称去除首尾空格后为空 | 阻止保存，名称输入框显示内联错误并聚焦 | 字段内联错误 | `“请填写主题名称”` |
| 保存主题单失败 | 本地写入失败 | 保留名称、人物、穿搭和备注草稿，显示重试入口 | Toast | `“主题单未保存成功，请重试”` |
| 保存灵感卡失败 | 本地写入失败 | 保留编辑态、标题、标签与备注 | Toast | `“灵感未保存成功，请重试”` |
| 选择器无主题单 | 用户从导入或详情进入主题单选择器，但尚无主题单 | 展示空态与「新建主题单」 | 空态 | `“还没有主题单，先建一个吧”` |
| 选择器无灵感卡 | 用户从主题单详情添加姿势库灵感，但姿势库为空 | 展示空态与「导入图片」 | 空态 | `“姿势库还是空的，先导入一张灵感图吧”` |
| 删除灵感卡 | 用户确认删除 | 弹窗明确说明会移出所有主题单；成功后返回姿势库 | 确认弹窗 | `“删除后将同时从已加入的主题单中移除，确定删除吗？”` |
| 删除主题单 | 用户确认删除 | 弹窗明确说明不会删除姿势库图片；成功后返回列表 | 确认弹窗 | `“删除主题单不会删除姿势库里的图片，确定删除吗？”` |
| 移出主题单 | 用户确认移除图片 | 仅删除当前引用，保留姿势库原图 | 确认弹窗 | `“仅从当前主题单移除，不会删除姿势库原图。”` |

### 7.3 相机与拍摄

| 异常场景 | 判定逻辑 | 交互 | 提示文案 | 文案示例 |
|---|---|---|---|---|
| 相机权限被拒绝 | 系统拒绝或用户拒绝相机权限 | 不进入实时相机，展示返回与查看权限指引 | 阻断页 | `“需要相机权限才能照着拍。请在系统设置中允许访问相机后重试。”` |
| 设备无可用相机 | 容器未提供可用摄像头 | 不显示取景画面，保留返回入口 | 阻断页 | `“当前设备暂时无法使用相机。”` |
| 相机初始化失败 | 已有权限但未能拉起相机流 | 停留错误页，提供「重试」和「返回」 | 页面错误状态 | `“相机打开失败，请重试”` |
| 参考图不可读 | 进入相机前图片读取失败 | 禁止进入相机，回到详情 | Toast | `“参考图无法读取，暂时不能照着拍”` |
| 拍摄失败 | 点击拍摄后无法生成结果图 | 保留实时相机与当前工具状态，提供重试 | Toast | `“拍摄失败，请再试一次”` |
| 结果保存失败 | 浏览器或系统无法保存结果 | 保留结果预览，允许重试或调用分享保存 | Toast | `“未能保存到设备，你可以重试或使用分享保存”` |

### 7.4 全局通用异常

项目暂未建立全局异常规范。首版不依赖网络完成私库、主题单和相机核心流程；如后续接入账户、官方远端内容或 AI 服务，须新增全局异常规范并以变更需求补充登录失效、网络超时、服务不可用、频率限制与第三方错误映射。

## 8. 数据变更与埋点

### 8.1 本次数据变更

新增以下仅存于当前设备的持久化记录。

#### 灵感卡

| 字段 | 业务含义 | 取值来源 / 生成规则 | 是否可修改 | 历史数据处理 |
|---|---|---|---|---|
| 图片 | 灵感复刻依据 | 用户导入的本地图片，或已配置的官方精选图 | 我的导入可删除；官方精选只读 | 不适用 |
| 标题 | 个人记忆名称 | 用户输入 | 是 | 不适用 |
| 通用标签 | 用于筛选的结构化信息 | 用户按需选择或新建 | 是 | 不适用 |
| 自由备注 | 非结构化补充信息 | 用户输入 | 是 | 不适用 |
| 来源类型 | 区分私库与官方内容 | 导入时写入`我的导入`；官方配置写入`官方精选` | 否 | 不适用 |
| 整理状态 | 标识标签完善程度 | 按 R2 与 5.3 字段规则计算 | 否，由标签状态自动更新 | 不适用 |

#### 主题单与关联关系

| 字段 | 业务含义 | 取值来源 / 生成规则 | 是否可修改 | 历史数据处理 |
|---|---|---|---|---|
| 主题名称 | 一次出行/拍摄收藏夹名称 | 用户输入 | 是 | 不适用 |
| 主题成员 | 主题内人物和穿搭说明 | 用户输入 | 是 | 不适用 |
| 自由备注 | 主题级补充信息 | 用户输入 | 是 | 不适用 |
| 主题引用 | 主题单与灵感卡的关联 | 用户通过选择器或主题内导入确认 | 是，可移出 | 删除主题单时删除引用；删除卡片时删除其全部引用 |

首版不在出片没内持久化拍摄成片或建立成片相册。用户确认保存后，成片交由设备系统的保存或分享能力管理；因此本次无拍摄结果的持久化数据变更。

### 8.2 埋点

首版可在用户同意匿名使用统计后采集以下**不含图片、标题、备注、标签内容和人物穿搭文本**的行为意图；具体事件名与参数待项目建立埋点总表后统一定义。

| 需观测行为 | 用途 |
|---|---|
| 导入开始、导入成功、导入失败原因 | 判断保存灵感的入口可用性 |
| 标签保存、筛选应用、搜索无结果 | 判断字段体系是否有用、是否过重 |
| 主题单创建、图片加入/移出主题单 | 验证主题单的准备价值 |
| 从灵感卡/主题单进入相机、拍摄成功、结果保存成功/失败 | 验证“照着拍”闭环 |
| 本地空间不足、相机权限拒绝 | 识别影响核心任务的系统障碍 |
