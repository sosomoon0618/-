# 出片没｜个人姿势库与主题单 PRD v1

> 关联：`00_MVP项目方案/出片没_MVP项目方案_v1.md`。页面原型与最终 UI 规格以 `01_交互确认单` 和确认后的 `02_低保真原型` 为准。

| 版本 | 日期 | 变更内容 |
|---|---|---|
| v1.0 | 2026-11-04 | 首版姿势库、主题单和本地数据规则 |

## 1. 背景与目标

### 1.1 背景

用户需要长期保存拍照灵感，也需要在一次出行前把相关图片集中准备。表格式工具字段完整但移动端录入和现场查找成本高；普通相册又缺少轻量筛选与主题准备能力。

### 1.2 目标

- 用户不填写表单也能导入一张灵感图。
- 用户能在个人私库中按关键词或少量结构化标签找回灵感。
- 用户能创建一个轻量主题单，记录人物穿搭、备注并引用已有灵感图。
- 灵感卡和主题单关系清晰：移出主题不删原图，删除原图才解除全部引用。

### 1.3 成功标准

| 指标 | 观测方式 |
|---|---|
| 导入完成率 | 导入开始到本地保存成功的比例 |
| 主题准备率 | 主题单创建后加入至少一张灵感图的比例 |
| 二次找回率 | 非首次使用时搜索、筛选或打开历史灵感卡的用户占比 |

## 2. 名词与数据约定

| 名称 | 定义 |
|---|---|
| 个人姿势库 | 当前设备上所有灵感卡的唯一总池。 |
| 灵感卡 | 一张参考图片及其标题、通用标签、自由备注和来源类型。 |
| 待整理 | 灵感卡已保存但未保存任何通用标签；仍可被浏览、加入主题单与按标题/备注搜索。 |
| 已整理 | 灵感卡至少保存一个通用标签。 |
| 主题单 | 一次出行或拍摄的轻量收藏夹；含名称、人物穿搭、自由备注、灵感卡引用。 |
| 主题引用 | 主题单与灵感卡的关联记录；不复制灵感卡图片。 |
| 通用标签 | 地点、点位、动作/行为、道具、人数、景别、光线和拍摄关键词。 |
| 拍摄关键词 | 用户自由添加的可搜索词，不再拆分“拍摄主题”字段；可同时承载游乐园、毕业、香水、朋友帮拍等内容主题和个人记忆。 |
| 本地保存 | 数据仅保存在当前浏览器/PWA。清除站点数据、卸载应用或更换设备可能造成不可恢复的丢失。 |

## 3. 范围

### 3.1 本次包含

- 单张图片本地导入、快速保存、补充整理。
- 灵感卡标题、通用标签、自由备注、查看、编辑、删除。
- 姿势库关键词搜索、主筛选与高级筛选。
- 主题单的新建、编辑、删除、人物穿搭、自由备注。
- 灵感卡加入多个主题单、从主题单移出、在主题内直接导入。

### 3.2 本次不做

| 不做项 | 原因 |
|---|---|
| AI 自动打标和自然语言检索 | 免费 MVP 不依赖云端 AI。 |
| 批量导入、批量编辑、导入链接解析 | 先验证随手单图保存的主路径。 |
| 云同步、账户与多人协作 | 本期本地优先。 |
| 行程、天气、地图、拍摄优先级和状态 | 主题单只做轻量收藏夹。 |
| 用户公开投稿、公开评分和社区 | 本期不引入审核与质量治理。 |

## 4. 用户与使用边界

首版不存在账户。所有用户可使用本地私库、主题单和筛选，不需要登录。官方精选与用户私库使用不同来源标识；用户私库默认不公开、不进入官方精选、不用于内容再分发或模型训练。

## 5. 功能详述

### 5.1 [姿势库]

**入口**：底部「姿势库」，首次启动的默认首页。  
**首屏优先级**：搜索/筛选与导入入口优先；已保存灵感卡其次；待整理入口仅在有内容时展示。

#### 展示字段

| 区域 | 字段 | 含义与来源 | 空值 / 异常展示 |
|---|---|---|---|
| 顶部 | 搜索词 | 用户输入；匹配标题、备注、所有通用标签 | 空时显示 `“搜索地点、动作或灵感”` |
| 顶部 | 主筛选 | 地点/点位、人数、景别、动作；点击后打开按字段分组的筛选面板 | 无可选值仍可打开筛选 |
| 卡片 | 图片 | 灵感卡原图或官方精选图 | 无法读取时显示图片占位与标题 |
| 卡片 | 标题 | 用户填写的个人记忆名称 | 空时显示 `“未命名灵感”` |
| 卡片 | 关键标签 | 地点、动作、人数、景别中已填的最多两类 | 无标签显示 `“待整理”` |
| 卡片 | 来源类型 | 我的导入 / 官方精选 | 固定显示 |

#### 交互矩阵

主筛选仅展示地点/点位、人数、景别与动作；点击任一主筛选或「筛选」均打开同一面板。面板按字段分组展示地点/点位、人数、景别、动作、拍摄关键词、整理状态；每组首项固定为「不限」。地点/点位、人数、景别、动作、拍摄关键词均可多选；整理状态为单选。

| 交互对象 | 可用条件 | 用户动作 | 即时反馈 | 成功结果 / 去向 | 异常 / 禁用 |
|---|---|---|---|---|---|
| 「导入」 | 容器可打开系统选图器 | 点击并选择一张图片 | 显示本地读取状态 | 成功后打开「快速整理」 | 读取失败见第 7 章 |
| 「搜索框」 | 姿势库存在卡片 | 输入或清空 | 列表即时按关键词刷新 | 保留匹配卡片 | 无命中显示筛选空态 |
| 「筛选」 | 姿势库存在卡片 | 打开「筛选面板」并应用 | 每组展示本字段可选值与「不限」；主筛选回显已选值 | 各维度间同时命中；同维度任一命中；点击某组「不限」只清空该组 | 取消/关闭回滚筛选草稿 |
| 「待整理」 | 待整理数量大于 0 | 点击 | 列表切换 | 只展示待整理卡片 | 无 |
| 任一灵感卡 | 卡片存在 | 点击 | 页面转场 | 进入灵感卡详情；返回保留搜索、筛选与滚动位置 | 无效图片仍可进入详情删除 |

#### 状态

| 状态 | 判定 | 展示与下一步 |
|---|---|---|
| 首次空态 | 没有任何灵感卡 | `“还没有灵感图，导入一张以后想拍的照片吧”` +「导入第一张图」 |
| 筛选无结果 | 有搜索词或筛选条件但无命中 | `“没有找到匹配的灵感”` +「清除筛选」 |
| 待整理列表 | 用户点击待整理入口 | 只显示未保存通用标签的卡片 |
| 图片不可读 | 存在记录但原图无法读取 | 保留元信息和删除入口，不尝试静默移除 |

### 5.2 [快速整理] 与灵感卡编辑

导入完成后进入「快速整理」。图片是唯一必填；用户可直接保存，也可填写标题、加入主题单或补少量标签。

| 字段 | 取值规则 | 是否影响整理状态 |
|---|---|---|
| 图片 | 本次选择的本地图片；不可编辑替换 | 不适用 |
| 标题 | 可空自由文本；去除首尾空格后保存 | 否 |
| 地点/点位/动作/道具/光线/拍摄关键词 | 可多选，允许新建个人标签，字段内去重 | 是 |
| 人数/景别 | 可空单选；新值覆盖旧值，点击已选值可清空 | 是 |
| 自由备注 | 可空长文本；参与关键词搜索但不进入筛选面板 | 否 |
| 加入主题单 | 可多选主题单；仅新增引用关系 | 否 |

**标签选择器**：多选字段打开时展示已选标签和本字段历史标签；用户可点击选中/取消或输入新词后「添加」。其中「拍摄关键词」是唯一承载未分类语义、内容主题和个人记忆词的自由标签字段，不再设置单独的“拍摄主题”字段。点击选择器「确定」仅写回详情页草稿；点击详情页「保存」后才持久化。取消、关闭或遮罩关闭均放弃本次草稿。

| 交互对象 | 可用条件 | 用户动作 | 即时反馈 | 结果 | 异常 / 禁用 |
|---|---|---|---|---|---|
| 「直接保存」 | 图片读取成功 | 点击 | 按钮进入处理中 | 新建灵感卡；有通用标签为`已整理`，否则为`待整理`；返回姿势库并显示 `“已存入姿势库”` | 本地保存失败时保留图片和表单 |
| 「保存并继续整理」 | 图片读取成功 | 点击 | 显示保存中 | 新建卡片并进入详情编辑态 | 保存失败原地重试 |
| 「保存」 | 灵感卡编辑态 | 点击 | 显示保存中 | 更新当前卡片并显示 `“已保存”` | 写入失败保留输入 |
| 「加入主题单」 | 至少存在一个主题单 | 点击打开选择器 | 显示草稿已选数量 | 确认后更新主题引用并回显主题名称 | 无主题单时引导新建 |
| 「取消/关闭」 | 未保存导入或选择器草稿 | 点击 | 关闭当前浮层 | 不创建/不变更记录 | 不弹二次确认 |

### 5.3 [主题单列表、详情与编辑]

主题单是独立对象，不能作为灵感卡的标签字段。

#### 主题单字段

| 字段 | 含义 | 规则 |
|---|---|---|
| 名称 | 当前出行/拍摄的收藏夹名称 | 必填；去除首尾空格后为空时显示 `“请填写主题名称”`；允许重名 |
| 主题成员 | 人物名称与穿搭说明 | 可添加多条；单条至少填写一项才保存；不绑定用户账户 |
| 自由备注 | 主题级任意说明 | 可空；不写回灵感卡 |
| 灵感图片 | 当前主题引用的灵感卡 | 可从姿势库多选，也可主题内直接导入；不复制原图 |

#### 主题单交互矩阵

| 交互对象 | 可用条件 | 用户动作 | 即时反馈 | 成功结果 / 去向 | 异常 / 禁用 |
|---|---|---|---|---|---|
| 「新建主题单」 | 始终可用 | 点击 | 页面转场 | 进入新建主题单页 | 无 |
| 「保存主题单」 | 名称非空 | 点击 | 显示保存中 | 新建后进入详情；编辑后返回详情并提示 `“已保存主题单”` | 写入失败保留草稿 |
| 「添加人物」 | 编辑态 | 点击 | 新增空人物行 | 可填人物与穿搭 | 无 |
| 「添加姿势库灵感」 | 姿势库有灵感卡 | 点击打开姿势库选择器 | 已在本主题的卡片预选 | 确定后一次性写入主题引用 | 无可选卡显示导入入口 |
| 「直接导入图片」 | 容器可选图 | 点击并选择图片 | 打开快速整理；当前主题预选 | 保存后自动加入当前主题单 | 图片失败见第 7 章 |
| 「移出主题单」 | 卡片在当前主题中 | 点击并确认 | 显示确认弹窗 | 仅删除当前主题引用，保留姿势库原图 | 取消不改变数据 |
| 「删除主题单」 | 主题单存在 | 点击并确认 | 显示确认弹窗 | 删除主题单、成员和全部引用，保留所有姿势库原图 | 取消不改变数据 |

## 6. 业务规则

| 编号 | 规则 |
|---|---|
| R1 | 一张灵感卡在个人姿势库中只存一份图片；任何主题单只保存引用。 |
| R2 | 用户可无标签保存灵感卡；标题、备注和主题引用不影响`待整理`/`已整理`判定。 |
| R3 | 不同筛选维度之间为同时命中；同一维度中多个值为任一命中。 |
| R4 | 用户私库默认仅当前设备可见；不公开、不进入官方精选、不用于模型训练或分发。 |
| R5 | 移出主题单只删除引用；删除灵感卡时必须同时删除全部主题引用。 |
| R6 | 删除主题单只删除主题自身、成员和引用，不删除姿势库图片。 |
| R7 | 官方精选必须有可用素材来源证明；用户私库图片不得被提升为官方内容。 |

## 7. 校验与异常

### 7.1 导入与本地保存

| 场景 | 判定逻辑 | 处理 | 用户文案 |
|---|---|---|---|
| 未选图 | 用户关闭系统选图器 | 返回入口，不创建记录 | 无 |
| 图片不可读 | 浏览器无法解码所选文件 | 不进入快速整理，允许重选 | `“图片读取失败，请重新选择”` |
| 本地空间不足 | 本地保存返回失败 | 保留当前表单和图片预览；不删除旧数据；允许重试 | `“本地空间不足，暂时无法保存。请删除不需要的灵感后重试。”` |
| 灵感保存失败 | 本地写入异常 | 保留输入与草稿，原地重试 | `“灵感未保存成功，请重试”` |

### 7.2 主题单与风险操作

| 场景 | 判定逻辑 | 处理 | 用户文案 |
|---|---|---|---|
| 名称为空 | 保存时名称去空格后为空 | 阻止保存，名称字段下显示错误 | `“请填写主题名称”` |
| 主题单保存失败 | 本地写入异常 | 保留名称、成员和备注草稿 | `“主题单未保存成功，请重试”` |
| 删除灵感卡 | 用户点击确认 | 删除卡片、图片、标签和全部主题引用 | `“删除后将同时从已加入的主题单中移除，确定删除吗？”` |
| 删除主题单 | 用户点击确认 | 删除主题单和引用，不删原图 | `“删除主题单不会删除姿势库里的图片，确定删除吗？”` |
| 移出主题单 | 用户点击确认 | 仅删除当前引用 | `“仅从当前主题单移除，不会删除姿势库原图。”` |

### 7.3 通用异常

首版不依赖网络完成私库与主题单主路径。项目尚未建立全局异常规范；后续引入账户、远端内容或 AI 时，须建立全局异常规范并新增对应变更需求。

## 8. 数据与观测

### 8.1 持久化数据

| 记录 | 内容 | 创建 / 删除规则 |
|---|---|---|
| 灵感卡 | 图片、标题、标签、备注、来源、整理状态 | 导入保存时创建；删除灵感卡时删除 |
| 主题单 | 名称、成员、备注 | 保存主题单时创建/更新；删除主题单时删除 |
| 主题引用 | 灵感卡与主题单关联 | 加入主题时创建；移出主题、删主题或删卡时删除 |

### 8.2 匿名观测

在用户同意匿名统计的前提下，仅记录导入成功/失败、主题单创建、加入主题、搜索/筛选、进入查看参考等行为；不得上传图片、标题、备注、标签文本、人物或穿搭内容。事件命名在项目建立埋点规范后补充。
