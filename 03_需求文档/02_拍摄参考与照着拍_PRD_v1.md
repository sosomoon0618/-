# 出片没｜拍摄参考与照着拍 PRD v1

> 关联：`00_MVP项目方案/出片没_MVP项目方案_v1.md`｜灵感卡来源、主题单关系见 `01_个人姿势库与主题单_PRD_v1.md`。页面原型与最终 UI 规格以 `01_交互确认单` 和确认后的 `02_低保真原型` 为准。

| 版本 | 日期 | 变更内容 |
|---|---|---|
| v1.0 | 2026-11-04 | 首版查看参考、构图辅助线与手机照着拍需求 |

## 1. 背景与目标

### 1.1 背景

用户收藏拍照灵感后，现场既可能使用手机拍摄，也可能由朋友持手机、使用相机或其它设备拍摄。因此“查看参考图并理解构图”必须独立于手机相机功能存在；把相机叠加作为唯一入口会限制真实使用场景。

### 1.2 目标

- 用户能在无需相机权限的情况下，打开一张参考图并查看构图细节。
- 用户可自行开关构图辅助线，辅助判断主体和画面位置。
- 用户需要用当前手机拍摄时，可在同一条路径进入参考图叠加相机。
- 首版全过程不做 AI 分析、不上传实时相机画面、不将辅助图层写入成片。

### 1.3 成功标准

| 指标 | 观测方式 |
|---|---|
| 参考查看使用率 | 从灵感卡或主题单进入查看参考的次数 |
| 构图线使用率 | 查看参考或相机内打开构图辅助线的次数 |
| 手机照着拍转化 | 从查看参考进入手机相机的比例 |
| 相机完成率 | 相机初始化成功到拍摄结果预览的比例 |

## 2. 名词与数据约定

| 名称 | 定义 |
|---|---|
| 查看参考 | 不调用相机的全屏/沉浸式参考图查看页，可用于任何拍摄设备场景。 |
| 构图辅助线 | 覆盖在参考图或相机取景区的三分法九宫格；默认关闭，仅视觉辅助。 |
| 用手机照着拍 | 用户主动从查看参考进入当前设备相机的模式。 |
| 参考图叠加层 | 在相机实时画面上显示的半透明参考图；可拖动、缩放和镜像。 |
| 成片 | 用户点击拍摄后生成的相机画面；不得包含参考图、构图辅助线或控制组件。 |
| 拍摄结果预览 | 拍摄后、用户保存到设备前的临时结果页；首版不在出片没内建立成片相册。 |

## 3. 范围

### 3.1 本次包含

- 从灵感卡详情、主题单灵感卡和底部「照着拍」进入参考图选择/查看。
- 参考图的放大、拖动、构图辅助线开关。
- 主动进入手机相机后的参考图透明叠加、透明度、镜像、构图线和倒计时。
- 拍摄成片、临时结果预览、调用设备可用的保存或分享能力。
- 相机权限拒绝、无可用相机、相机初始化失败、参考图不可读、拍摄或保存失败等处理。

### 3.2 本次不做

| 不做项 | 说明 |
|---|---|
| 人体轮廓/骨架提取、姿势评分、动作纠正、自动快门 | 后续 AI 或端侧识别能力，不属于免费 MVP。 |
| 参考图自动识别机位、焦段、曝光或光线 | 不做 AI 解析。 |
| 在出片没中管理拍摄成片、编辑或修图 | 成片由系统保存/分享能力处理。 |
| 用相机直接控制外部相机设备 | 查看参考支持该场景，但不与外部相机连接。 |
| 视频录制、连拍、滤镜、消路人、文案生成 | 超出首版验证范围。 |

## 4. 用户与权限边界

所有用户可查看参考，不需要登录。相机权限仅在用户点击「用手机照着拍」后才申请；用户拒绝权限不影响其继续查看参考、缩放参考图或返回主题单。首版不上传参考图、实时取景、成片或权限状态。

## 5. 功能详述

### 5.1 [参考图选择器]

**入口**：底部「照着拍」。  
**目的**：让未从特定灵感卡进入的用户先选择一张参考图，而不是直接打开相机。

| 区域 | 内容 | 来源 | 空值 / 异常 |
|---|---|---|---|
| 顶部 | 搜索与返回 | 用户输入、页面入口 | 取消后回到进入前页面 |
| 筛选 | 地点/点位、人数、景别、动作 | 姿势库通用标签 | 无标签时允许只浏览 |
| 卡片流 | 所有可读取灵感卡 | 个人姿势库 | 无卡片时显示导入引导 |

| 交互对象 | 可用条件 | 用户动作 | 即时反馈 | 结果 / 去向 | 异常 / 禁用 |
|---|---|---|---|---|---|
| 任一可读取灵感卡 | 姿势库存在可读图片 | 点击 | 页面转场 | 进入[查看参考]并带入所选卡片 | 无 |
| 搜索/筛选 | 有灵感卡 | 输入或应用筛选 | 列表刷新 | 显示匹配卡片 | 无结果显示 `“没有找到匹配的灵感”` |
| 取消/关闭 | 选择器打开 | 点击 | 关闭 | 返回进入前页面，不请求相机权限 | 无 |
| 空态「去导入」 | 姿势库为空 | 点击 | 页面转场 | 进入姿势库导入路径 | 无 |

### 5.2 [查看参考]

**入口**：灵感卡详情的「查看参考」、参考图选择器选图、主题单中的灵感卡详情。  
**目的**：让用户以任意拍摄设备完成“看着参考拍”的任务；这是拍摄能力的默认入口。

#### 展示字段

| 区域 | 字段 / 文案 | 含义与来源 | 空值 / 异常展示 |
|---|---|---|---|
| 导航 | 返回、页面标题 | 当前查看参考路径 | 始终展示返回 |
| 主图区 | 参考图 | 当前灵感卡的原图 | 不可读时不进入本页，见第 7 章 |
| 主图区 | 构图辅助线 | 用户临时开关状态 | 默认关闭；打开时显示三分法九宫格 |
| 提示区 | 缩放与拖动提示 | 固定引导文案 | `“双指缩放 · 拖动查看细节”` |
| 底部 | 「用手机照着拍」 | 手机相机入口 | 始终可点击，不预先请求权限 |

#### 交互矩阵

| 交互对象 | 可用条件 | 用户动作 | 即时反馈 | 结果 / 去向 | 异常 / 禁用 |
|---|---|---|---|---|---|
| 参考图 | 图片已读取 | 双指缩放、单指拖动 | 图片实时改变显示区域 | 仅改变本页临时查看状态 | 离开页面后不保存缩放位置 |
| 「构图辅助线」 | 页面已打开 | 点击开关 | 九宫格即时显示/隐藏 | 不修改原图、不写入灵感卡标签 | 离开页面后恢复默认关闭 |
| 「用手机照着拍」 | 当前参考图可读取 | 点击 | 显示 `“正在打开相机”` 并请求相机权限 | 授权后进入[用手机照着拍] | 权限拒绝/相机异常见第 7 章 |
| 返回 | 页面已打开 | 点击 | 页面返回 | 返回灵感卡详情或参考图选择器，保留来源页状态 | 无 |

### 5.3 [用手机照着拍]

**入口**：仅从[查看参考]的「用手机照着拍」进入。  
**目的**：在当前手机的实时取景画面上叠加参考图，辅助用户复刻姿势和构图。

#### 展示字段

| 区域 | 内容 | 来源 | 规则 |
|---|---|---|---|
| 顶部导航 | 退出、页面标题 | 固定组件 | 退出后关闭相机流并返回查看参考 |
| 取景区 | 实时相机画面 | 当前设备相机 | 不上传、不存储实时画面 |
| 取景区 | 参考图叠加层 | 进入页面的灵感卡图片 | 默认半透明；可拖动、缩放、镜像 |
| 取景区 | 构图辅助线 | 用户临时开关 | 默认关闭；独立于查看参考页的临时状态 |
| 工具栏 | 透明度、镜像、构图线、倒计时 | 用户临时操作 | 离开相机后全部恢复默认 |
| 底部 | 拍摄按钮 | 固定操作 | 相机可用且不在倒计时时可点击 |

#### 交互矩阵

| 交互对象 | 可用条件 | 用户动作 | 即时反馈 | 结果 / 去向 | 异常 / 禁用 |
|---|---|---|---|---|---|
| 透明度控制 | 相机已可用 | 拖动控制条 | 叠加层即时变透明/不透明 | 仅改变本次相机临时状态 | 无 |
| 参考图叠加层 | 相机已可用 | 拖动、双指缩放 | 叠加层即时移动或缩放 | 仅改变本次临时位置/大小 | 无 |
| 镜像 | 相机已可用 | 点击 | 参考图左右翻转 | 不翻转实时相机画面 | 无 |
| 构图线 | 相机已可用 | 点击 | 九宫格即时显示/隐藏 | 不写入成片 | 无 |
| 倒计时 | 相机已可用且未倒计时 | 点击选择倒计时；再次点击取消 | 显示倒计时或取消提示 | 结束时自动执行一次拍摄；取消时不产生结果 | 倒计时中禁用重复启动 |
| 拍摄 | 相机已可用且未倒计时 | 点击 | 显示拍摄中，禁用重复点击 | 生成不含叠加层/构图线的成片并进入结果预览 | 拍摄失败时保留相机画面 |
| 退出 | 相机页面打开 | 点击 | 关闭相机流 | 返回查看参考；不保存临时工具状态 | 无 |

### 5.4 [拍摄结果预览]

| 交互对象 | 可用条件 | 用户动作 | 即时反馈 | 结果 / 去向 | 异常 / 禁用 |
|---|---|---|---|---|---|
| 结果图 | 已完成拍摄 | 展示 | 显示不含辅助图层的成片 | 可保存到设备或重拍 | 无 |
| 「保存到设备」 | 结果图存在 | 点击 | 显示保存中 | 调用浏览器可用的系统保存/分享能力；首版不在应用内建立成片相册 | 系统拒绝保存时保留结果图与重试入口 |
| 「重拍」 | 结果图存在 | 点击 | 返回相机 | 丢弃未保存结果，恢复相机 | 无 |
| 返回 | 结果图存在 | 点击 | 返回来源页 | 未保存结果丢弃 | 不弹二次确认 |

## 6. 业务规则

| 编号 | 规则 |
|---|---|
| R1 | 查看参考不调用相机、不请求相机权限，可独立完成参考查看任务。 |
| R2 | 构图辅助线为三分法九宫格，默认关闭；查看参考与相机页分别维护临时开关状态。 |
| R3 | 构图辅助线、参考图缩放位置、相机叠加位置/大小/透明度/镜像均仅对当前会话有效，退出对应页面后恢复默认。 |
| R4 | 用手机照着拍只能从查看参考进入，保证用户已明确选择参考图。 |
| R5 | 参考图叠加层和构图辅助线仅用于取景显示，不得进入成片。 |
| R6 | 首版不上传相机画面、参考图或成片，不输出任何 AI 姿势、衣着或构图判断。 |
| R7 | 首版不在应用内持久化成片；成片只通过设备提供的保存或分享能力交给用户。 |

## 7. 校验与异常

### 7.1 参考图

| 场景 | 判定逻辑 | 处理 | 用户文案 |
|---|---|---|---|
| 参考图不可读 | 当前卡片原图读取失败 | 阻止进入查看参考或相机，返回详情 | `“参考图无法读取，暂时不能查看或照着拍”` |
| 姿势库为空 | 从底部照着拍入口进入且无可读卡片 | 展示导入空态 | `“先导入一张灵感图，再开始照着拍”` |
| 筛选无结果 | 选择器应用搜索/筛选后无卡片 | 保留筛选条件并显示清除入口 | `“没有找到匹配的灵感”` |

### 7.2 相机与保存

| 场景 | 判定逻辑 | 处理 | 用户文案 |
|---|---|---|---|
| 相机权限被拒绝 | 系统或用户拒绝授权 | 不进入相机，展示权限说明与返回查看参考入口 | `“需要相机权限才能用手机照着拍。请在系统设置中允许访问相机后重试。”` |
| 无可用相机 | 容器未提供摄像头 | 不显示取景画面，允许返回 | `“当前设备暂时无法使用相机。”` |
| 初始化失败 | 已有权限但无法拉起相机流 | 展示重试与返回 | `“相机打开失败，请重试”` |
| 拍摄失败 | 无法生成结果图 | 保留实时相机与当前临时工具状态 | `“拍摄失败，请再试一次”` |
| 保存失败 | 系统或浏览器无法保存结果 | 保留结果预览，允许重试/分享保存 | `“未能保存到设备，你可以重试或使用分享保存”` |

### 7.3 通用异常

首版没有远端 AI、账户或云端数据任务。网络异常不会阻断已在本地保存的参考查看与相机主路径；后续接入远端服务时另建全局异常规范与变更需求。

## 8. 数据与观测

本需求不新增相机画面或成片的应用内持久化数据。仅在用户同意匿名统计时记录：进入查看参考、打开/关闭构图线、从查看参考进入相机、相机初始化成功/失败、拍摄成功/失败、保存尝试成功/失败。不得上传参考图、相机流、成片或任何用户文字内容。
