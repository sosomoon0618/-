# 出片没｜MVP 项目方案 v1

## 1. 产品定位

**出片没**帮助用户将日常收集的拍照灵感，整理为出行或拍摄现场可以快速找到、查看并照着拍的参考库。

首版不是姿势社区，也不是 AI 相机。它验证的核心价值是：**个人灵感私库 + 一次性主题单 + 参考查看/手机引导拍摄**。

## 2. 用户与问题

| 用户 | 现状问题 | MVP 的回应 |
|---|---|---|
| 灵感收集者 | 截图散在相册和聊天记录中，之后找不回 | 个人姿势库、搜索与轻量筛选 |
| 出行准备者 | 会提前想好拍什么，但手机多维表格录入/查找很累 | 主题单收集本次要看的参考图 |
| 现场拍摄者 | 看到参考图仍难以判断构图、姿势和手机位置 | 全屏查看参考、可开关构图辅助线、可选手机叠加相机 |

## 3. 首版产品结构

```text
个人姿势库（长期全量池）
   └─ 灵感卡：图片 + 可选通用标签 + 备注
          ↕ 可被多个主题单引用
主题单（一次出行/拍摄的轻量收藏夹）
   └─ 名称 + 人物与穿搭 + 自由备注 + 灵感图片引用
          ↓
查看参考（任意拍摄设备都可用）
   └─ 可选：用手机照着拍
```

## 4. 首版目标与成功标准

| 目标 | 可观测信号 |
|---|---|
| 用户愿意保存灵感 | 完成导入并保留灵感卡 |
| 用户愿意为具体活动做准备 | 创建主题单并加入灵感图 |
| 用户在现场真的使用参考 | 从灵感卡或主题单进入查看参考 / 手机照着拍 |
| 私库能被再次找回 | 非首次使用时发生搜索、筛选或再次打开 |

## 5. 首版范围

### 做

- 本地个人姿势库：导入、浏览、标题/备注、结构化标签与自由「拍摄关键词」、搜索与筛选。
- 主题单：名称、人物及穿搭、自由备注、从私库选择图片、主题内直接导入。
- 查看参考：全屏图、放大、拖动、可开关三分法构图辅助线。
- 用手机照着拍：参考图叠加、透明度、镜像、构图线、倒计时、拍摄结果保存至设备。
- 小规模、素材授权清晰的官方精选内容。

### 不做

- 云同步、账户、跨设备迁移；社区、投稿、点赞评论。
- 自动抓取第三方平台图片、公开分发用户私库图片。
- 云端 AI 自动打标、语义搜索、AI 建主题、姿势评分、修图或文案。
- 行程、地图、天气、拍摄优先级和拍摄状态管理。

## 6. 免费与第二阶段 AI

首版的完整主路径免费可用，且不调用云端 AI。后续 AI 只作为效率层：自动提取地点/动作等已存在标签、自然语言搜索、根据私库生成主题单、轮廓/骨架辅助和实时建议。

AI 进入时需要独立定义：用户授权、图像是否离开设备、免费试用、点数扣减、失败降级和隐私文案；不把这些规则提前写入免费 MVP。

## 7. 隐私与版权底线

- 用户导入图片默认仅在当前设备私库可见，不进入公开内容、模型训练或官方素材。
- 官方精选只允许自制、明确授权或可商用素材。
- 本地数据可能因清除浏览器站点数据、卸载 PWA 或更换设备而丢失；首版需明确提示。
- 相册、相机权限仅在用户主动导入或启动手机拍摄时申请。

## 8. 阶段路线

1. 交互确认单与低保真原型：先验证导航、主题单、筛选和“查看参考”的可用性。
2. 首版开发：本地私库、主题单、查看参考、手机引导拍摄。
3. 小范围测试：验证导入、建主题、现场查看/拍摄的连续使用。
4. 第二阶段：基于真实行为决定 AI 与云同步优先级。

## 9. 启动前外部前置

- 确认首批兼容的移动浏览器与相机/保存能力范围。
- 确认官方精选内容素材授权与审核流程。
- 确认是否启用不含图片和文本内容的匿名行为统计。
